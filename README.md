# Creator's — The Creator Intelligence Platform

> **"Instead of another AI that creates content, build software that helps creators understand the business and performance of their content."**

**Creator's** is a dual-mode web platform (Public Marketing Site + Creator Workspace App) designed to address the 10 real problems faced by modern content creators on YouTube, TikTok, and Instagram.

---

## 🌟 The 10 Core Problems & Intelligent Solutions

1. **Algorithm Detective ("Why Did My Video Die?")**: Diagnoses why views collapsed (e.g. 100k → 424 views) by pinpointing the exact 8-second viewer retention cliff, sub-baseline CTR, and velocity penalties, complete with actionable experiments.
2. **Creator Scientist (Pattern Discovery)**: Statistically mines your last 50 videos to reveal what actually works (18–32s length, bold text hook, face appearance in first 2s) vs. what underperforms (intros >4s, generic topics). Includes a pre-production hypothesis tester.
3. **Originality & Copycat Monitor**: Scans YouTube and TikTok for automated AI channels scraping your original scripts, concepts, and hooks, providing 1-click DMCA takedown templates.
4. **Sponsor Radar (Brand Discovery Engine)**: Database of active paying sponsors filterable by niche and audience geography (US, Kenya, UK, etc.) with verified contacts and a tailored pitch generator.
5. **Creator Rate & Deal Calculator**: Multi-factor commercial pricing engine. Factors in production labor, audience CPM, paid ad whitelisting (+40%), and exclusivity windows.
6. **Monetization Risk Scanner**: Pre-upload policy scanner evaluating 2025/2026 YouTube "Inauthentic Content" rules and un-commentated third-party footage thresholds before publishing.
7. **Platform Change Tracker ("Creator Changes")**: Real-time radar tracking algorithm, monetization, and disclosure shifts across YouTube, TikTok, and Instagram with personalized catalog impact warnings.
8. **Smart Content Recycler**: *"Human chooses, AI accelerates."* Identifies high-tension viral moments in long videos with potential scores and 1-click 9:16 vertical crop export.
9. **Qualified Revenue Analytics**: Step-by-step waterfall demystifying TikTok Creator Rewards: Total Views (255k) → Disqualification filter → Qualified Views (168.4k) → RPM ($1.62) → Payout ($274.37), explaining what drove your RPM.
10. **Creator Deal Pipeline CRM**: Full visual Kanban board (`New` → `Pitched` → `Negotiating` → `Active` → `Delivered` → `Paid`), deliverable checklist, follow-up alerts, and commercial invoice exporter.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Glassmorphism, Modern Dark Mode
- **Icons**: Lucide React
- **Build**: Vite 6

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application in the browser.

### Build
```bash
npm run build
```
The production bundle will be created in the `dist/` directory.
